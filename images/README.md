# Images Directory

This folder contains images used on the Polarisk website.

## Image Naming Convention

Images should include resolution in the filename for easy replacement:
- `logo-200x50.png` - Logo at 200x50 pixels
- `hero-1920x1080.jpg` - Hero image at 1920x1080 pixels
- `icon-48x48.svg` - Icon at 48x48 pixels

## Current Images

No images are currently required. The landing page uses inline SVG graphics.

## Future Images

When adding images:
1. Use descriptive names
2. Include resolution in filename
3. Optimize for web (compress JPGs, use WebP where possible)
4. Provide @2x versions for retina displays if needed
