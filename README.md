# Polarisk Website

Next.js app-router website for Polarisk.

## Tech Stack

- Next.js 16
- React 19
- App Router
- Next font optimization (Inter)

## Local Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Notes

- Main brand assets live in `public/`.
- Current homepage uses pitch-deck-aligned messaging with a sleek dark UI theme.

## Github action 
Github actions is setup for Deployment to Live website
